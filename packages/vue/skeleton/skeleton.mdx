# Skeleton

載入中的骨架佔位元件。

有三種形態：帶 `variant` 時為文字條（高度依語意排版類型計算），帶 `circle` 時為圓形，其餘為方塊。
`width` 與 `height` 可傳數字（視為 px）或 CSS 字串。
